machine learning

Es una rama de la inteligencia artificial que permite a los sistemas aprender automáticamente a partir de datos, sin necesidad de ser programados con reglas específicas para cada tarea. En lugar de escribir instrucciones paso a paso, se entrena un modelo con grandes cantidades de información para que identifique patrones y relaciones. A partir de ese aprendizaje, el sistema puede hacer predicciones, clasificar información o tomar decisiones. Se utiliza en aplicaciones como recomendaciones de contenido, detección de fraudes, predicción del clima y muchos otros campos.

9 conceptos fundamentales de Machine Learning

Conjunto de datos


Grupo de muestras utilizado para entrenar y evaluar un modelo

Instancia


Una sola muestra dentro de un conjunto de datos

Atributo


Característica de la instancia

Etiquetas


La variable que se intenta predecir

Algoritmo


Serie de reglas con un objetivo específico

hiperparámetros


Valores que se ajustan para entrenar un modelo y modifican su rendimiento o capacidad en general.

Modelo


Resultado de entrenar un algoritmo con un conjunto de datos de entrenamiento.

Sobreajuste


Un modelo tiene buen rendimiento con el conjunto del de entrenamiento, pero malo con el de validación

subajuste


Un modelo tiene mal rendimiento con el conjunto del de entrenamiento, pero bueno con el de validación
